# Project Documentation

> This folder is git-ignored. It holds internal project documentation that stays local to each developer's machine. Share files via your team's preferred channel (Notion, Confluence, Google Drive, etc.).

## Structure

```
project-docs/
├── requirements/        # Product requirements and feature specs
│   └── PRD.md           # Product Requirements Document
├── architecture/        # System design and architecture decisions
│   └── ADR-template.md  # Architecture Decision Record template
├── api/                 # API contracts and endpoint documentation
│   └── endpoints.md     # API endpoint reference
├── design/              # UI/UX specs, wireframes, design tokens
│   └── design-specs.md  # Design specifications
├── meetings/            # Meeting notes and decisions
│   └── .gitkeep
├── runbooks/            # Operational runbooks and playbooks
│   └── deployment.md    # Deployment checklist
└── changelog/           # Internal changelog and release notes
    └── CHANGELOG.md     # Version history
```

## Usage

1. Copy template files and fill in project-specific details
2. Remove sections that don't apply
3. Add new docs as the project evolves
